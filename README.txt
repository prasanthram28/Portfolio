# Prasanth Portfolio

A responsive, dark, Solo Leveling-inspired developer portfolio built with:

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript

## Folder structure

portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── profile.jpg
    ├── project-parking.png
    ├── project-chat.png
    └── project-neurofocus.png

## Setup

1. Open the project folder in VS Code.
2. Put your profile image at:
   assets/profile.jpg
3. Put project screenshots in the assets folder using the filenames used in index.html.
4. Open index.html with Live Server.
5. Replace placeholder contact links and GitHub links with your real links.

## Notes

The contact form is currently a frontend demo. It does not send email yet.
The project links are placeholders until real GitHub/demo URLs are added.
